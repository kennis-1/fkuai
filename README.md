# 俄罗斯方块 · Tetris（单文件网页版）

一个用纯 HTML / CSS / JavaScript 写的俄罗斯方块小游戏。所有代码都打包在单个 `index.html` 里，**无需任何依赖、无需联网，双击即玩**。

## 玩法

- **键盘**：`←` `→` 移动 · `↓` 软降 · `↑` / `X` 旋转 · `Z` 反向旋转 · `C` 暂存 · `空格` 硬降 · `P` 暂停 / 继续
- **触屏**：在手机等触屏设备上会自动显示方向控制按钮
- **目标**：填满整行即可消除得分，方块下落速度随等级提升

## 技术特点

- **单文件**：HTML + CSS + JS 全部内联，零外部资源
- **画面**：使用 Canvas 绘制，包含落点预测、暂存区（Hold）、下一个方块预览
- **离线可玩**：直接打开 `index.html` 即可运行
- **最高分**：通过 `localStorage` 在本地保存

## 本地运行

直接双击 `index.html`，或在该文件夹下用任意静态服务器打开。

## 在线访问

已部署到 Vercel：https://fkuai-jiayan.vercel.app

源码托管于 GitHub（`kennis-1/fkuai`），通过 Vercel 连接 GitHub 仓库实现**自动部署**——每次 `push` 新代码，线上网站会自动重新构建并更新。
